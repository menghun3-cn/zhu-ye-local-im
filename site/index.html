它做什么

v1 · Windows 与 Android

六件事，每一件都只发生在你自己的网络里。点开任意一张看它到底怎么工作。

局域网里直连

设备互相发现，然后直接开一条 TCP 连接。数据不经过任何第三方。

  • UDP 47654 自动发现，两台设备出现在彼此的列表里
  • TCP 47655 承载文件、消息与剪贴板
  • 发现不到时，可以手动填对方 IP 直连

发现即自动连接

附近运行本程序的设备被发现后，会自动校验身份、建立设备组关系并打开数据连接。

  • 发现后直接建立连接，没有按钮、配对码或接受请求
  • 连上即可发送文字、图片、文件和表情
  • 设备组关系会记住，重启或短暂断网后自动恢复

图片到达即显，文件要你点头

两者待遇不同，是有意的：图片像消息一样「到了就到」，文件要你亲自同意才落盘。

  • 图片与文字直接送达，不弹确认；但文件每次都要点「接收」
  • 点了「接收」就直接收下，不再追问存到哪个文件夹
  • 类型按扩展名自动分辨，图片不裹气泡、点击可放大

剪贴板镜像

在一台设备上复制，另一台上直接粘贴 —— 只在你自己的设备组里发生。

  • 三档：关闭 / 问我 / 镜像
  • 默认拒绝所有人，要按设备逐个勾选
  • 界面如实标出每台设备「能读 / 能写」的实际能力

微信式的对话

左列会话、右侧消息流。传文件、发图片、聊天在同一个地方完成。

  • 回车发送、Shift+回车换行；长文件名折行显示，不会被截断
  • 右键「打开所在目录」「复制图片」
  • 别人发来的文件就地显示「接受 / 拒绝」，不用换页

桌面端该有的细节

该安静的安静，该听话的听话。

  • 单实例：重复启动只会叫出已在运行的那个窗口
  • 关闭按钮最小化到托盘，也可以设成直接退出
  • 可以开机自启（默认关闭），侧栏底部会提示新版本

说明

系统要求
Windows 10 1809 或更高版本，64 位。VC++ 运行库已随包附带（就放在 exe 旁边）， 目标机器不需要另外安装任何东西。
数据写在哪
设备身份与设备组关系在 %APPDATA%\LocalTransfer\profile.json —— 它含本机密钥，删掉等于恢复出厂；附近的设备会在重新发现后自动建立关系。 收到的文件与图片默认落在 %USERPROFILE%\Downloads\LocalTransfer\，可以在设置页改。
外网
程序平时只和局域网说话。唯一一次访问外网是你点「检查更新」的时候： 它会去 GitHub 查这个项目有没有发布过更新的版本，然后把版本号显示在侧栏底部。 不点，就不会发生。
已知限制
会话历史只存在内存里，关掉程序就清空；剪贴板镜像是约 0.7 秒一次的轮询实现， 会有轻微延迟；同一台机器上不要同时开两个本程序（发现用的 UDP 端口只能被一个进程持有）。
许可与源码
源码在 GitHub， 用 Flutter 写成。分支模型、提交规范与质量门禁都写在仓库的 AGENTS.md 里。
