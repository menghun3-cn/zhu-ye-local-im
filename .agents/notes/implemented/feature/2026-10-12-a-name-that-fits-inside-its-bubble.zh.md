# Agent Note：让文件名在自己的气泡里放得下

Status: implemented

## Problem

文件气泡是按固定宽度画的——宽度由名字量出，下限 `transferBubbleMinWidth`、
上限 `transferBubbleMaxWidth`（280）——而名字本身是 `maxLines: 1` +
`TextOverflow.ellipsis` 的 `Text`。于是任何宽过上限的名字都被砍成「前半截 +
`…`」，而被丢掉的那半截总是在**末尾**：扩展名、版本号、平台标签。对这个应用
真正要传的那些名字（`…-windows-x64-portable.zip`）来说，被丢掉的恰恰是用户
看气泡就是想看的那一半。

宽度本身是对的，不动它：跟着名字长的气泡会横穿会话面板，而气泡里那条进度条
自己没有宽度可依。错的是把它整条上限花在**一行**上——而这一块的高度是不要钱的。

## Decision

**一行放不下的名字折行，最多三行。**

- 新增 `WeChat.transferNameMaxLines = 3`，两处名字 `Text`（`_body` 里的文件块、
  `_image` 里图片图标旁的名字）都取它作 `maxLines`；`TextOverflow.ellipsis`
  保留，病态长的名字仍然会停。
- 名字样式加上 `height: WeChat.lineHeightBody`，即正文已经在用的行高。单行只高
  约 3px；两行三行是能读的，而不是挤在一起的。
- **量宽的部分一点没改**。`_transferBubbleWidth` 依旧按**未折行**的单行宽度量，
  依旧 clamp。这不是疏忽：上限正是让长名字折行的那条线，所以单行宽度恰好就是
  「要不要套上限」的判据。反过来去量折行后的高度就成了循环——宽度取决于在哪断
  行，断行又取决于宽度。
- 因为宽度仍然从名字量出，**放得下的名字仍然是一行、仍然是它自己的宽度**。折行
  只给本来就没地方的名字加行，从不给放得下的名字多加一行余量。

三行不是第四个量：它就是上限本来就蕴含的东西。上限宽一行约放 18 个半角字符，
三行只是同一条上限往下带，而它覆盖这个应用会产生的一切名字。

## Testing

`test_flutter/ui/transfer_bubble_test.dart`——本来就归它管气泡宽度：

- 新增：「a name too long for the bubble wraps instead of losing its end」，
  发一个 `local-transfer-1.0.0-windows-x64-portable-full.zip`，钉四件事：
  `maxLines` 是 `transferNameMaxLines`、溢出仍是省略号、画出的宽度不超上限
  （折行不许把气泡撑宽）、画出的高度超过一行（确实折了）。
- 扩充：原有的宽度测试现在同时断言那个五字符的名字只占一行。光有上限分不出短名
  和长名，分得出的是「量」——这条断言正是「量」哪天被上限取代时会红的那条。

## Alternatives considered

**提高上限，让更多名字能挤进一行。** 否：那只是把漏斗往右挪，不是在修。任何上限
都存在比它更长的名字，而 280 已经差不多是文件卡片还读得出是文件卡片的那条线。

**只对长名字放宽上限。** 否：现有的「量」到上限为止本来就是这么做的。过了上限
就没有宽度可给了——除非把气泡变成整行宽，而那正是这个气泡当初被造出来要避免的
事，所以只剩「行数」这一种货币。

**名字用滚动/跑马灯。** 否：让用户去追的名字，比一个占两行高的名字更差。而连三行
都放不下的名字，气泡的提示里本来就有全文。

**从中间省略（`…-portable.zip`）。** 否：平台没有这种原语，而名字不是路径——在两
个地方切断只会让人更难一眼看清，不是更容易。

**所有名字都给三行位置。** 否：那是同一个错误的反面——短名字会白带两行空白，气泡
的高度会变成「最坏情况」而不是「内容多少」。

## Consequences

**换来的。** 文件名的尾巴重新看得见了：扩展名、版本、平台。而气泡本来就已经装着
名字、大小行、进度条和两个按钮，最多只再多两行字。

**放弃的。** 超长名字下的纵向紧凑——一个会话里堆几个长名字文件会比以前高。三行是
天花板，所以代价是有界、可预期的。

**没有动任何用户可见文案**，打包探针因此无需增删，条数仍是 29。

**新测试从未跑过。** 本机起不了 `flutter test`（任何带管道的 `Process.start` 都
报 `CreateFile failed 231`）；这次实跑欠在一台工具链正常的机器上，和它旁边那些
气泡测试一样。
