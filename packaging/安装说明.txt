竹叶局域网传输 —— Windows 安装版（x64）
======================================

【怎么装】
双击 LocalTransfer-x.y.z-windows-x64-setup.exe，一路「下一步」即可：
- 装到 %LOCALAPPDATA%\Programs\LocalTransfer，也就是
  C:\Users\<你的用户名>\AppData\Local\Programs\LocalTransfer。
- 不需要管理员权限，不会弹 UAC —— 本程序不装驱动、不注册服务、不写系统目录。
- 默认不建桌面快捷方式；想放一个就在向导里勾上「创建桌面快捷方式」。
- 开始菜单里会出现「竹叶局域网传输」。

【怎么卸】
设置 → 应用 → 已安装的应用 → 找到「竹叶局域网传输」→ 卸载；
也可以直接运行安装目录里的 unins000.exe。

⚠️ 卸载**不会**删掉你的设备身份。它存在
%APPDATA%\LocalTransfer\profile.json，和安装目录无关 —— 这是故意的：
那份文件里有本机密钥，删掉等于恢复出厂；附近的设备会在重新发现后自动建立新关系。
真要清干净，卸载之后再手动删掉那个文件。

【怎么升级】
下载新版安装包直接运行即可 —— 原地覆盖升级，不必先卸载，
设备身份与设备组关系都不受影响；重启后会自动恢复连接。

程序自己也会在启动时静默问一次 GitHub 上发布了哪个版本：有新版本时，
左侧菜单栏最下方会出现一个「更新」按钮，鼠标移上去显示新版本号，
点它就用浏览器打开下载页。这是本程序唯一一次主动访问外网的动作，
且不发送任何内容。

【功能怎么用】
本文件只讲「装」这件事。功能、自动连接、防火墙、排错、已知限制等，见同目录下的
「使用说明.txt」—— 那一份与绿色免安装版完全相同。

【和绿色免安装版的区别】
- 安装版：装进用户目录，有开始菜单项与卸载项，升级靠重装安装包。
- 绿色版：解压即用，不写注册表，想删就直接删掉整个文件夹。
两者是同一份程序文件，选一个用就行，不要两份都装还同时开着
（会发现端口被占用 —— 自动发现用的 UDP 端口只能被一个进程持有）。

【系统要求】
- Windows 10 1809 或更高版本，64 位。
- VC++ 运行库已随包附带（vcruntime140.dll / vcruntime140_1.dll /
  msvcp140.dll 就在 exe 旁边），目标机器不需要另外安装任何东西。

【首次运行请放行防火墙】
程序只用三个端口，全部在本局域网内，不连外网：
- UDP 47654：自动发现
- TCP 47656：自动建立设备组信任
- TCP 47655：建立信任后的数据通道
Windows 首次运行会弹防火墙询问，请勾上「专用网络」再点「允许访问」。
漏了这一下，「设备」页里就看不到对方。详细排错见「使用说明.txt」。
安装版没有替你代加防火墙规则，因为那需要管理员权限，与「不弹 UAC」冲突。

【安全提示】
本程序只做局域网直连，没有服务端、没有账号、没有云端，所有流量都在本局域网内。
未做代码签名，首次运行 SmartScreen 可能提示「未知发布者」，
点「更多信息」→「仍要运行」即可。
